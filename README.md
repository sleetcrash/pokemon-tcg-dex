# Pokemon TCG Art/Illustration Dex

Personal tracker for collecting the National Dex in Art Rare, Illustration Rare, and Special Illustration Rare cards. 
- Single self-contained HTML file.
- No dependencies & works offline.

## Features

- 1,179 entries: all 1,025 species plus regional forms and mega evolutions
- Search to find Pokémon, filter by generation, region, and form. 
- List view and Binder view. Toggle 3x3 or 4x4 binder. 
- Named lists: save and load snapshots of your checks
- Sync codes: Currently syncs via code, future updates will have this sync automatically. currently everything is saved locally. 

## Future

- Long-press an entry to replace the sprite with an image of the actual card in binder view. Current binder view just shows the sprite.
- Trainers per region.
- Language.
